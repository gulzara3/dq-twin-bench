# Supplementary figures

Per-subset figures written by the benchmark run. They correspond to Figs. S1
to S40 of the supplementary material of the paper.

| Files | Content | Supplementary figures |
|---|---|---|
| `figA_degradation_<subset>_<model>_RMSE.pdf` | RMSE against fault severity | S1 to S12 |
| `figA_degradation_<subset>_<model>_PICP.pdf` | interval coverage against fault severity | S13 to S24 |
| `figB_heatmap_<subset>_sev3.pdf` | RMSE increase at severity 3 by fault and architecture | S25 to S28 |
| `figC_scatter_<subset>_LSTM.pdf` | clean-input predictions with 95% intervals | S29 to S32 |
| `figD_radar_<subset>.pdf` | sensitivity profile of the three architectures | S33 to S36 |
| `figE_reliability_<subset>_LSTM.pdf` | reliability diagram of the conformal intervals | S37 to S40 |
